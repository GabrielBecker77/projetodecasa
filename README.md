# Exercícios em Java

Repositório para prática contínua de desenvolvimento de software em Java e consolidação de fundamentos da linguagem.

## Habilidades e Conceitos Praticados

* Programação Orientada a Objetos (POO): Classes, objetos, encapsulamento e construtores.
* Lógica & Estrutura: Algoritmos, laços de repetição, condicionais e manipulação de arrays.
* Tratamento de Exceções & Boas Práticas: Validação de entradas e tratamento de erros (try-catch).
* Recursos do Java: Manipulação de datas, strings e entrada/saída de dados via console.
